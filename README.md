# Portfolio App (Expo)

This is a personal portfolio asset tracking application built with Expo and React Native.

## Features
- Real-time asset tracking
- Skeleton loading screens for better UX
- Supabase integration
- Multi-currency support (KRW, USD, JPY)
- **Automatic FX Rate Caching**: Persists last successful USD/KRW and JPY/KRW rates to ensure stable profit calculation even when API is unavailable.
- **Data Integrity Indicator**: Visual indicators (Red dot) when cached FX data is in use.
